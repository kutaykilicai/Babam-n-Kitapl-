# Babamın Kitaplığı

Babam için yaptığım tek sayfalık okuma günlüğü. Okunan kitaplar tür, sayfa sayısı, puan ve notlarla kaydedilir; aylık kitap sayısı, tür dağılımı, en uzun ve en kısa kitap gibi istatistikler ile küçük başarımlar gösterilir.

Veriler tarayıcının `localStorage` alanında tutulur, sunucu gerektirmez. `index.html` dosyasını tarayıcıda açmak yeterli.
